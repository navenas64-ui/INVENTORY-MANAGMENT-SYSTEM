# Inventory Management System

A simple Inventory Management System developed using Python, Streamlit and SQLite.

## Features

- Add Product
- View Products
- Update Product
- Delete Product
- Search Product
- Low Stock Alert
- Dashboard

## Technologies Used

- Python
- Streamlit
- SQLite

## How to Run

1. Install the required packages:
   ```
   pip install -r requirements.txt
   ```

2. Run the application:
   ```
   streamlit run app.py
   ```
